Physics W1 is below the authors' reimplementation of LOTUS in 6/6 held-out patients and is below it pooled. In a post hoc comparison with the original LOTUS code, physics W1 is lower in 5/6 patients and lower pooled. Supplementary Table~S2.16 gives the null per stage and post hoc frame-bootstrap intervals for W1 and KID. The established-simulator rows run the same protocol with the renderer swapped (exploratory).
